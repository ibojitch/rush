# いぼ次元ラッシュ — v0.50 Color Trail

スマートフォン横持ちとPC向けのブラウザ2Dアクション。
`index.html` と `ibojigen_sprite_atlas_1280x456.png` を同じ場所に置いて開きます。
GitHub Pagesでも外部ライブラリなしで動作する構成です。

## 操作

- PC: ← → / A D 移動、Space / W ジャンプ、I / J ミサイル
- Esc 一時停止、R 現在のステージをリトライ、Enter メニュー決定
- スマートフォン: 横持ち、左側で移動、右側でジャンプと発射
- 音は初期OFF。上部の「音 OFF」を押すとBGMと効果音が有効になります。
- ゲームオーバー、クリア後は画面のボタンから再開・次の面へ進めます。

## この版の変更

- 16コマのアトラスを、8列×2行・セル/ピッチ160×228pxの1280×456 PNGに再配置。大きな透明余白を削減し、各コマはセル内で下中央揃え。
- ミサイルは発射位置から384ゲーム内px（画面幅の2/5）。壁に当たっても消滅。
- 発射の反動、弾の光と軌跡、足元の影、ジャンプ時の粒子。
- 草原・夕焼け・星あかりの3ステージ。基本コースを共有し、浮き足場・コイン・敵編成・背景・音を変更した初期バリエーションです。
- 往復する敵、羽のある飛行敵、目印のある跳躍敵。
- 簡易シンセBGMと効果音。外部音源は未使用。
- ジャンプ入力の先行受付120ms、足場を離れた後の猶予100ms。
- 浮き足場は下から通過可能。接触時は小さく後退、落下時は直近の安全な足場に復帰。
- 60Hz固定ステップで画面のリフレッシュレートによる物理挙動の差を抑制。
- タイトル、一時停止、音切替、横持ち案内、タッチでの再試行。

## 構造と素材

現在は1つのHTML内で関数ごとに処理を分けています。`SPRITE_ATLAS` が画像サイズ・セル・ピッチの仕様、`SPRITE_TILES` が全16コマの名前と矩形、`themes` が背景と音、`buildLevel` が配置、`makeEnemy` が敵の初期値です。

元画像は `ibojigen_sprite_atlas_source_1774x887.png` として保存しています。Windows PowerShellで `powershell -File tools/repack_sprite_atlas.ps1` を実行すると、ゲーム用の `ibojigen_sprite_atlas_1280x456.png` を再生成できます。配置順や元画像の切り出し範囲を変える場合は、スクリプトの `$frames` と `index.html` の `SPRITE_TILES` を同時に更新してください。外部ライブラリは不要です。

## 検証

`node tests/logic.cjs` でゲームロジックのテストを実行できます。Node.jsの標準モジュールのみ使用します。
構文、全16コマの範囲、左右の射程、ジャンプ猶予、復帰、メニューからの再試行、3面の遷移、敵の継続更新、基本ルート到達を確認します。
DOM/Canvasを代替したテストであり、ブラウザの描画・実機のタッチ・音の再生品質は保証しません。

この作業環境ではブラウザ起動とローカルHTMLの表示が制限され、目視試遊は未実施です。公開前にPCとスマートフォンで表示・同時タッチ・音・難易度を確認してください。
