# いぼ次元ラッシュ — v0.60

スマートフォン横持ちとPC向けの、ブラウザ2Dアクションゲームです。
`index.html` と `ibojigen_sprite_atlas.png` を同じフォルダに置いて開きます。外部ライブラリは不要で、GitHub Pagesでも動作します。

## 操作

- PC: ← → / A D 移動、Space / X ジャンプ
- 声アイテム取得後: P / S / B / V 声攻撃
- 通常弾アイテム取得後: I / Z 通常弾
- Esc: 一時停止
- R: ステージ1からリトライ
- ゲームオーバー時: C または画面の「コンティニュー」で現在ステージから再開
- クリア画面: I / X または画面ボタンで次のステージへ
- スマートフォン: 横持ち。左側スティックで移動、右側ボタンでジャンプ・声攻撃・通常弾

コンティニューではSCOREが0に戻ります。ハイスコアはブラウザに保存されます。

## アイテムと得点

### SCORE

- 干し芋取得: +2
- 敵撃破: 敵の種類・攻撃能力に応じて +1〜+4
- ステージクリア: +10

SCOREは5ステージを通して累積し、BEST SCOREとしてブラウザに保存されます。

### 干し芋

マップ上で拾える得点アイテムです。

- 声アイテム取得後は、声エネルギーを+5回復
- 取得ごとに1%で大きなハートが出現
- 累計10個ごとに50%でスターが出現

### 声アイテム

最初に倒した敵が落とします。取得すると声エネルギーが50になり、最大値は100です。

- プ: 消費8、短射程
- ス〜: 消費12、中射程
- ブリブリ: 消費20、長射程
- ヴリヴリブー: 消費30、最長射程

エネルギーが足りないときは攻撃できず、「プス」という小さな失敗音と白いフォグが出ます。

### 通常弾アイテム

開始時は通常弾を使えません。ステージ2で弾を撃つ敵を倒すと金色の玉が出現し、取得すると通常弾が解禁されます。

通常弾は横方向の射程制限はなく、重力0.20で落下します。

### その他

- ハート: HPが減っているとき、HPを1回復
- 大きなハート: 最大HPを1増やし、全回復
- スター: 約8秒間無敵。敵に触れるだけで通常敵を倒せます

## ステージと敵

草原・夕焼け・星あかり・紅蓮・次元最深部の全5ステージです。

- 通常敵、ツノ付きの跳躍敵、飛行敵が出現
- ツノ付きの敵は踏みつけでは倒せず、接触するとダメージ
- 後半ステージでは敵が通常ビームを撃つ
- ステージ5にはHP3の青いボスが出現
  - 通常ビームと、赤い長距離レーザーを薙ぎ払う攻撃を使う
  - 撃破するまでゴール前の封鎖が消えず、クリアできない
  - 被ダメージ後は短時間点滅して無敵になる
  - 体当たりではボスはダメージを受けず、主人公が大きくノックバックする

## デバッグモード

- Ctrl + D: デバッグモードのON/OFF（HUDに`[DEBUG]`表示）
- デバッグモード中に F: 声攻撃・通常弾を解禁し、HPと声エネルギーを全回復
- デバッグモード中に 1〜5: 対応するステージの最初から開始

## 構造と素材

ゲーム本体は `index.html` 1ファイルです。

- `SPRITE_ATLAS`: スプライトアトラス仕様
- `SPRITE_TILES`: 主人公・敵の16フレーム
- `KOE_TILE`: 声エネルギー水筒アイテムの領域
- `themes`: 各ステージの背景色と音楽
- `buildLevel`: ステージの配置
- `makeEnemy`: 敵・ボスの初期値

ゲーム用アトラスは8列×3行、実画像サイズ1280×684です。元のアトラス素材は `old/ibojigen_sprite_atlas_source_1774x887.png` にあります。

PowerShellで次を実行すると、アトラスを再生成できます。

```powershell
powershell -File tools/repack_sprite_atlas.ps1
```

## 検証

次のコマンドで、ゲームロジックの自動テストを実行できます。

```powershell
node tests/logic.cjs
```

構文、操作、5ステージ進行、SCORE・ハイスコア、アイテム解禁、声エネルギー、敵ビーム、スター、ステージ5ボス、デバッグ操作などを確認します。

自動テストはDOM/Canvasを代替して実行するため、実際のブラウザ描画、スマートフォン操作、音の聞こえ方は保証しません。公開前にはPC・スマートフォンでの試遊確認をおすすめします。
